# Figure icons

Small PDF renderings of Font Awesome Free 7.3.1 icons (https://fontawesome.com; icon artwork
CC BY 4.0, Fonticons, Inc.), used by the hand-drawn manuscript figures (`../fig8_defense_path.tex`
and the other TikZ figures). `make_icons.py` lists the icons and regenerates them from the
`svgs/solid` directory of the `@fortawesome/fontawesome-free` npm package; each icon is rendered
as a white glyph for coloured header bands and in a few dark colours for light boxes.
